Shop App

A full-stack e-commerce web application built using Node.js, Express.js, MongoDB, and EJS, with session-based authentication, RESTful APIs, and real-time communication using WebSockets.

Features

- Authentication & Sessions: Session-based user authentication and login management.
- Password Reset: Token-based password reset with expiration.
- Product Management: Browse products and manage products through admin functionality.
- Shopping Cart: Add products, update quantities, and remove items.
- Order Management: Place orders and manage order status.
- RESTful APIs: Handle application data through HTTP methods such as GET, POST, PUT, and DELETE.
- Real-Time Communication: WebSocket functionality implemented using Socket.IO.
- Database Integration: MongoDB and Mongoose for data storage and management.
- Server-Side Rendering: Dynamic pages rendered using EJS.
- Security: CSRF protection, session cookies, and secure configuration practices.

Tech Stack

- Backend: Node.js, Express.js
- Frontend: EJS, HTML, CSS, JavaScript
- Database: MongoDB, Mongoose
- Real-Time Communication: Socket.IO
- API Testing: Postman
- Deployment: Render

Project Purpose

This project demonstrates practical full-stack web development skills, including authentication, session management, REST API development, database operations, real-time communication, and deployment.
